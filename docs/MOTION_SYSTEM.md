# Motion System

- Hero routes animate data movement between named system nodes.
- Selected Systems transitions one authentic product state at a time.
- Publishing workflow shows ordered operational handoffs.
- Menus, controls, and focus states use short ease-out transitions.

Content exists in the DOM and remains visible without motion. `prefers-reduced-motion` removes route animation and collapses transitions to near-instant state changes. No animation blocks interaction or carries unique meaning.
