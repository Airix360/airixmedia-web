# Publishing Architecture W8

Publishing is an explicit Oyo Knowledge route family, not a hero-only claim. The
public architecture covers the hub, OJS, universities, journal platforms, hosting
and support, editorial support, plugins and pricing.

The OJS workflow is described as configurable: submission, editorial assessment,
review, revision, production, publication and discovery/preservation. No universal
journal process, indexing acceptance, DOI ownership, partnership or outcome is
claimed.

Hosting/support crosses from Oyo to Rivers because editorial understanding and
maintained infrastructure are distinct but connected responsibilities. Plugins
cross from Oyo to Kaduna through verified public repositories.
