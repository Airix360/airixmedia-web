# Information Architecture

Top-level navigation: Services, Publishing, Selected Systems, Insights, Company, Support, Portal, and Start a Project.

The Services menu groups five practices. Publishing receives its own hub and specialist routes without becoming the whole company identity. Proof separates client/venture systems from open-source engineering. Support separates standard help, existing-client access, and emergency recovery.

Critical conversion paths end in a qualified project brief; consultation booking follows review rather than replacing qualification.
