# SEO Baseline

## Current themes

The current site has recent relevance around OJS setup, hosting, support, pricing, migration, recovery, and publishing operations. This authority should be preserved while building new topical clusters for websites, e-commerce, applications, managed operations, and recovery.

## Technical baseline

- English uses unprefixed canonical URLs; French and Portuguese use `/fr` and `/pt`.
- Metadata templates, canonical links, `hreflang`, sitemap, robots, Open Graph defaults, and semantic page headings are implemented.
- Structured-data expansion should cover Organisation, Service, Article, FAQ where genuine, CreativeWork, and SoftwareSourceCode.
- Thin location pages and keyword-stuffed industry pages are prohibited.
