# Design System

The system uses true white and neutral near-black themes, Archivo typography, Fragment Mono labels, a twelve-column grid, sharp borders, controlled radii, and five practice accents in OKLCH.

The hero and major narratives are full canvas. Cards are reserved for actual grouped or interactive objects. Interface frames, route diagrams, status points, and authentic screenshots carry the technical story. Both themes preserve contrast and hierarchy.

The existing Airix mark remains the prototype identity. Refinements require separate owner approval.
