# Accessibility W8

W8 corrects the inherited public-adaptation debt through conventional landmarks,
one page `h1`, visible skip access, explicit navigation labels, labelled fields,
native controls, text alternatives, keyboard-accessible mobile navigation, Escape
close with focus restoration, touch-sized controls and complete reduced-motion
content.

Axe 4.12.1 ran against the homepage, Publishing, Infrastructure, Studio, Open
Source, Atlas, Discuss and Emergency routes using WCAG A/AA tags. On 15 July 2026,
all eight routes returned zero critical or serious violations in desktop and mobile
Chromium. The focused Playwright gate completed with 19 passes and three intentional
cross-project skips. Automated results do not replace manual keyboard, screen-reader,
contrast, cultural or owner review.
