# Integrations

The prototype uses server-side adapter interfaces and mock responses.

- Twenty CRM: validated lead and opportunity payloads
- Google Calendar: post-review booking handoff
- Chatwoot: prospect, client, and emergency routing
- Uploads: disabled UI placeholder pending encrypted storage and retention design
- Exchange rates: deterministic prototype simulation with final quote precedence
- Umami: environment-controlled, privacy-conscious analytics direction
- Payload CMS: future content adapter, not a runtime dependency

Keys never enter client bundles. External unavailability must not break public rendering.
