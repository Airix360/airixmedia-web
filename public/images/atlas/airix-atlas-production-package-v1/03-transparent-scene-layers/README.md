# Atlas Group 3 — Transparent Scene Layers

Five optimized transparent WebP depth layers are provided for every Group 1 master:

1. Atmosphere
2. Distant world
3. Midground structures
4. Surface / water / roads
5. Foreground activity

Use these for restrained parallax, fades, scene transitions, and responsive compositing.

These are art-directed depth mattes derived from flattened illustrations. They are
not exact object-by-object cutouts. Reusable isolated objects are produced separately
in Group 4.
