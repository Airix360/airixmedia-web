# Naming Convention

Use lowercase kebab-case.

Illustrations:
`ill-####-descriptive-name.ext`

Objects:
`obj-####-descriptive-name.ext`

Icons:
`ico-####-descriptive-name.svg`

Textures:
`tex-####-descriptive-name.ext`

Responsive suffixes:
- `desktop-16x9`
- `tablet-4x3`
- `mobile-4x5`
- `social-og`
- `thumbnail-16x9`

Transparent depth layers:
- `01-atmosphere`
- `02-distant-world`
- `03-midground-structures`
- `04-surface-water-road`
- `05-foreground-activity`
