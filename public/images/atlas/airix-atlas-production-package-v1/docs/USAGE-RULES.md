# Usage Rules

Visual direction:
- Gongbi technique
- Lagos subject matter
- Atlas palette
- Nigerian cultural and architectural grounding
- Avoid generic futuristic architecture
- Avoid false, fabricated, or illegible public signage in publication assets

Before publication:
1. Review all generated text and signage.
2. Verify landmark accuracy.
3. Replace fabricated logos and labels.
4. Confirm people and clothing remain culturally appropriate.
5. Optimize raster exports for delivery.
6. Use SVG for interface icons and markers.
7. Preserve transparent PNG masters before WebP conversion.
