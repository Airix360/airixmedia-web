# Atlas Group 2 — Responsive Crops

This package contains responsive WebP exports for the 10 Group 1 master scenes.

Variants per scene:
- desktop-16x9 — 1600×900
- tablet-4x3 — 1200×900
- mobile-4x5 — 1080×1350
- social-og — 1200×630
- thumbnail-16x9 — 640×360

Crop focal points and source crop boxes are documented in `manifest.json`.

These are candidate production crops. Final publication should happen only after
the selected masters are cleaned of generated text, logos, and landmark errors.
