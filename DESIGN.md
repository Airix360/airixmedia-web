# Design System

## Visual thesis

A monochrome digital control surface shaped by Lagos routes, intersections, lagoon boundaries, and dense infrastructure, with crisp interfaces and small signals of practice colour.

## Theme

True white and neutral near-black surfaces. Light and dark modes receive equal hierarchy, contrast, and motion treatment. The system uses sharp borders, restrained radii, visible grids, large editorial type, and layered interfaces without decorative glass.

- Dark background: `oklch(0.09 0 0)`

## Typography

Archivo provides the main voice: engineered, direct, and legible at editorial scale. Fragment Mono is limited to compact system labels, data, and status details. Display sizes remain below 96px and use balanced wrapping.

## Layout

A twelve-column desktop grid collapses to six and then four columns. Full-canvas hero and narrative sections use edge-to-edge compositions; text remains within readable measures. Cards appear only for real interactive or grouped objects.

## Motion

Hero systems assemble along routes, publishing stages hand work forward, and selected-system screens transition between states. All content is visible without animation. Reduced motion uses static states or short crossfades.

## Components

Navigation, mega menu, locale and theme controls, buttons, link treatments, verification flags, system maps, practice rows, case-study frames, workflow stages, forms, pricing comparisons, project selector, and legal navigation share documented tokens.
